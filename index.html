Live Browser App

Air Writer Live

Open your camera in the browser and write in air with hand gestures. This version runs directly on the page, so anyone with a modern browser can use it.

Camera is off. Click Start Camera to begin.

Gesture Map

  • Right index draws
  • Right middle opens color mode
  • Right ring opens tool mode
  • Right pinky saves a screenshot
  • Right open palm erases
  • Left thumb + index shrink or grow brush size

What Works Online

This Vercel-hosted version uses browser camera access and MediaPipe hand tracking. It works best in Chrome, Edge, and other modern Chromium browsers.

Important Limit

A website can use your webcam in-browser, but it cannot become a system-wide Zoom camera device by itself. For Zoom camera output, use the desktop version in the GitHub repo.

Need The Desktop App?

The full local version with virtual camera support is still included in the repository for people who want OBS-style camera output.
