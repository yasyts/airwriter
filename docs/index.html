Local Desktop App

Air Writer Studio

A gesture-based air writing tool that turns your webcam feed into a live drawing surface, then publishes that output as a virtual camera you can select inside Zoom, Google Meet, Teams, and similar apps.

Gesture Map
  • Right index writes in air
  • Right middle opens color mode
  • Right ring changes tool
  • Right pinky saves a screenshot
  • 4 fingers (no pinky) auto screenshot + clear
  • Right open palm erases
  • Left thumb + index change brush size
Launch Air Writer Virtual Camera.bat

How It Works

The app uses MediaPipe hand tracking and OpenCV to detect gestures, draw dark high-contrast strokes, and preview the result locally in real time.

Use It In Zoom

Install the dependencies, launch virtual camera mode, then choose OBS Virtual Camera inside your meeting app.

python desktop_app.py --virtual-camera

Connect To Other Apps

For OBS, Streamlabs, Discord, Loom, or recording tools, open the desktop app and add it with window capture, display capture, or normal screen sharing.
